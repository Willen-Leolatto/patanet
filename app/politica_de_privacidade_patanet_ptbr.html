Política de Privacidade — PataNet App

Última atualização: 18/02/2026

1. Quem somos

O PataNet App é um aplicativo voltado para comunidade pet, com recursos como feed, perfis de usuários, perfis de pets, carteira de saúde (vacinas, vermifugação, medicamentos) e eventos.

Contato do desenvolvedor: dev.patanet@gmail.com

2. Quais dados coletamos

Podemos coletar e processar os seguintes dados, conforme o uso do aplicativo:

  • Dados de conta: e-mail, senha (armazenada de forma segura/criptografada no servidor), nome de usuário.
  • Dados de perfil: nome, foto de perfil e informações que você escolher adicionar.
  • Conteúdo gerado pelo usuário: publicações, comentários, fotos enviadas e informações de pets.
  • Dados de eventos: informações do evento e, quando aplicável, localização do evento (coordenadas/descrição).
  • Dados técnicos: dados necessários para autenticação e funcionamento do app (por exemplo, tokens de sessão).

Observação: o aplicativo pode evoluir para incluir ferramentas de analytics. Caso isso ocorra, esta política será atualizada.

3. Como usamos os dados

  • Para criar e gerenciar sua conta e permitir login seguro.
  • Para exibir e operar funcionalidades do app (feed, perfis, pets, carteira de saúde e eventos).
  • Para prevenir abuso, fraudes e melhorar a segurança.
  • Para suporte e comunicação, quando você entrar em contato conosco.
  • Para melhorias do produto (ex.: métricas/analytics), quando habilitado.

4. Localização

O PataNet pode utilizar informações de localização associadas a eventos (ex.: endereço/descrição e/ou coordenadas). A utilização de localização do dispositivo (GPS) pode depender de implementação futura e de permissões do sistema.

5. Compartilhamento de dados

Não vendemos dados pessoais. O compartilhamento pode ocorrer apenas quando necessário para:

  • Operação do serviço (ex.: provedores de hospedagem/infraestrutura).
  • Cumprimento de obrigações legais.
  • Proteção de direitos, segurança e prevenção de fraudes.

Se ferramentas de analytics forem ativadas, poderemos compartilhar dados técnicos/estatísticos com provedores de analytics.

6. Segurança

Adotamos medidas de segurança para proteger seus dados. Ainda assim, nenhum sistema é 100% seguro. Recomendamos que você use uma senha forte e não compartilhe seu acesso.

7. Retenção e exclusão

Mantemos os dados pelo tempo necessário para operar o app e cumprir obrigações legais. Você pode solicitar remoção de conta/dados pelo e-mail dev.patanet@gmail.com.

8. Crianças e adolescentes

O PataNet não é direcionado a crianças. Caso identifiquemos coleta indevida, tomaremos medidas para remoção.

9. Alterações nesta política

Podemos atualizar esta política periodicamente. Publicaremos a versão atualizada e revisaremos a data de “Última atualização”.
